# Trees

Rooted Newick trees of the stable families found in each text of the pre-registered Bédier test (`code/historic/families_to_newick.py` from `data/bedier/classification_a10/`). Internal node labels (quoted): family, w = support in units, s = bootstrap stability. Witnesses not grouped by any stable family hang from the root.

`lai_ombre_unrooted.nwk`: the unrooted tree of the *Lai de l'Ombre* read from Bédier's 1913 apparatus (CG 176, DE 43, AB 38, DEF 24 units); see `data/lai_ombre/`.
